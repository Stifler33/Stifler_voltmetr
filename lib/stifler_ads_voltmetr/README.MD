## ⚡ Stifler\_voltmetr: Библиотека Вольтметра ADS1115 (0-30 В)

Эта библиотека представляет собой расширение для популярной библиотеки **Adafruit\_ADS1X15** и предназначена для удобного считывания напряжения в диапазоне от **0 до 30 Вольт** с использованием АЦП **ADS1115** (или ADS1015) с внешним делителем напряжения.

Предполагается, что к аналоговому входу ADS1115 подключен **делитель напряжения**, который преобразует входное напряжение **0-30 В** в диапазон, подходящий для АЦП (в данном случае, **0-2.047 В**), что соответствует установленному внутреннему коэффициенту усиления (PGA) **GAIN\_TWO** ($\pm 2.048\text{ В}$).

-----

### 📥 Установка

1.  Установите базовую библиотеку **Adafruit\_ADS1X15** через Менеджер библиотек Arduino.
2.  Добавьте файлы `stifler_voltmetr.h` и `stifler_voltmetr.cpp` в ваш проект или как пользовательскую библиотеку.
3.  Включите заголовочный файл в вашем скетче:
    ```cpp
    #include "stifler_voltmetr.h"
    ```

-----

### ⚙️ Аппаратная Конфигурация

Библиотека разработана для использования **ADS1115** с внешним делителем напряжения, который масштабирует входное напряжение 0-30 В в диапазон 0-2.047 В.

  * **ADS1115** должен быть подключен к вашей микроконтроллерной плате по шине **I2C**.
  * К одному из аналоговых входов АЦП (например, A0, A1, A2 или A3) должен быть подключен выход **делителя напряжения**.
  * Также используется дополнительный цифровой пин (**pin\_error**) для проверки, корректно ли подключен измеряемый источник (например, аккумулятор).

-----

### 🚀 Использование (API)

Класс `Stifler_voltmetr` наследуется от `Adafruit_ADS1X15`.

#### 1\. Инициализация и Настройка

Инициализируйте объект и вызовите метод `begin()` для настройки АЦП. По умолчанию устанавливается коэффициент усиления **GAIN\_TWO** ($\pm 2.048\text{ В}$), что позволяет максимально точно считывать напряжение до $2.047\text{ В}$ с делителя.

```cpp
Stifler_voltmetr voltmeter;

// Инициализация
// channel: Аналоговый канал ADS1115 (0, 1, 2 или 3)
// pin_error: Цифровой пин для проверки наличия подключения (PIN_ERROR)
// i2c_address: I2C адрес ADS1115 (по умолчанию 0x48 / 72U)
// wire: Указатель на объект шины I2C (по умолчанию &Wire)
bool success = voltmeter.begin(0, PIN_ERROR_CHECK, 72U, &Wire);

if (!success) {
    // Обработка ошибки инициализации
}
```

#### 2\. Установка Коэффициента Пересчета (Delta)

Необходимо установить коэффициент пересчета (`delta`), который используется для преобразования сырого цифрового значения АЦП в милливольты. Он рассчитывается на основе максимального ожидаемого напряжения ($30000\text{ мВ}$) и максимального цифрового значения АЦП ($32767$ для $2.048\text{ В}$ с ADS1115).

$$
\Delta = \frac{\text{max\_mv}}{\text{max\_adc\_value}}
$$

```cpp
// max_mv: Максимальное напряжение в милливольтах (30 В * 1000 = 30000 мВ)
// max_adc_value: Максимальное цифровое значение для выбранного усиления/диапазона
voltmeter.set_delta(30000, 32767); 
```

#### 3\. Чтение Напряжения

##### 3.1. Простое Чтение

Считывает и возвращает измеренное напряжение в **Вольтах** (float). Не проверяет состояние пина `pin_error`.

```cpp
float voltage = voltmeter.read_voltage(); // Возвращает напряжение в Вольтах
```

##### 3.2. Чтение с Проверкой Подключения

Считывает напряжение и сохраняет его по указателю `*value`, но только если цифровой пин **pin\_error** находится в состоянии **HIGH** (т.е., если измеряемый источник подключен правильно).

  * Возвращает `true`, если чтение выполнено успешно (пин `pin_error` был HIGH).
  * Возвращает `false`, если измеряемый источник не подключен (пин `pin_error` был LOW).

<!-- end list -->

```cpp
float measured_voltage;
if (voltmeter.read_voltage(&measured_voltage)) {
    // Источник подключен, measured_voltage содержит значение в Вольтах
    Serial.print("Напряжение: ");
    Serial.print(measured_voltage);
    Serial.println(" В");
} else {
    // Источник не подключен
    Serial.println("Источник не подключен.");
}
```

### 💡 Принцип Работы Делителя

Библиотека основана на предположении, что внешний делитель напряжения был рассчитан для преобразования **0-30 В** в диапазон **0-2.047 В**.

1.  **ADS1115** настроен на усиление **GAIN\_TWO**, что соответствует полному диапазону (Full Scale Range, FSR) $\pm 2.048\text{ В}$.
2.  Максимальное цифровое значение для ADS1115 в однополярном режиме (16 бит, не дифференциальный) составляет $\approx 32767$.
3.  Ваш делитель должен давать на выходе **2.047 В** при входном напряжении **30 В**.

Это обеспечивает возможность измерения до $30\text{ В}$ с хорошим разрешением, даже если номинальный диапазон ADS1115 меньше выходного напряжения делителя ($2.048\text{ В} < 2.47\text{ В}$), поскольку калибровка (через `set_delta`) учитывает преобразование $30\text{ В}$ в $32767$ отсчетов АЦП.

> **Внимание:** Максимальное входное напряжение для ADS1115, при использовании GAIN\_TWO, составляет $2.048\text{ В}$. Подача $2.47\text{ В}$ на вход превышает этот диапазон, хотя в данном случае `set_delta` и $32767$ предполагают, что **2.47 В** будут считаны как максимальное цифровое значение. При использовании **GAIN\_TWO** на ADS1115, $1\text{ LSB}$ равен $0.0625\text{ мВ}$. При $2.047\text{ В}$ на входе это может привести к ограничению (saturate) значения на $32767$.
